# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
Ron Deniele D. Paragoso's existing portfolio presents web development, video editing, digital art, professional experience, services, skills, writing, and contact details.

## Capabilities and Constraints
The user requires Cutesy Forge: a single-viewport illustrated blacksmith workshop whose objects open the existing portfolio panels. Preserve real portfolio content, project previews, external links, discipline routes, theme switching, keyboard access, and existing functionality. No invented professional claims. The workshop must not require page scrolling; existing detail panels retain their content and controls.

## Brand Commitments
Cozy chibi fantasy workshop, orange cat blacksmith, cream, orange, amber, leather brown, and sage. Generate and integrate original artwork. The user supplied the orange cat blacksmith reference during implementation; it is preserved as the main mascot, with generated object art based on that reference.

## Evidence on Hand
lib/site.ts, lib/dashboard.ts, lib/blog.ts, existing dashboard components and public project screenshots.

## Accessibility & Inclusion
Readable responsive panels, large touch targets, keyboard access, visible focus, reduced motion support. Mobile must offer a compact object menu instead of shrinking desktop hit targets.
